## 🎯 Key Files Location

### API Architecture
```
src/api/
├── axiosInstance.js      ← Central HTTP layer
├── httpClient.js         ← Reusable methods
├── endpoints.js          ← Centralized endpoints
├── errorNormalizer.js    ← Error handling
└── tokenManager.js       ← Token storage

src/features/auth/
├── auth.service.js       ← Service orchestration
├── authThunks.js         ← Redux async actions
├── authSlice.js          ← Redux state
└── authSelectors.js      ← Redux selectors
```

### Scroll Management
```
src/utils/
└── scrollUtils.js        ← Scroll utilities (7 functions)

src/layout/
└── RootLayout.jsx        ← Automatic scroll-to-top
```

### Redux Setup
```
src/store/
├── index.js              ← Store configuration
└── rootReducer.js        ← Root reducer

src/main.jsx              ← Redux Provider setup
```
